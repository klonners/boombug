# BoomBug assets

Upload game assets (images, audio, sprites, fonts, etc.) into this `asset/` folder.

Keep filenames simple, for example:
- `splash.mp3`
- `fly.png`
- `background.png`

When using an asset in the game, reference it with a path like `asset/splash.mp3` from `index.html`.

Files added here in this GitHub repository can be inspected by the assistant when helping update BoomBug.
